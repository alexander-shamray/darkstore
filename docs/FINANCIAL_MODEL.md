# Упрощённая финансовая модель Dark Store

**Проект:** Dark Store — быстрая доставка продуктов  
**Локация:** Костанай, Казахстан  
**Период прогноза:** 12 месяцев  
**Дата создания:** Май 2026  
**Валюта:** Тенге (тг)

---

## 1. Введение

Данная модель показывает ожидаемые финансовые результаты проекта при разных сценариях развития. Модель упрощённая и предназначена для быстрой оценки viability проекта.

**Основные допущения:**
- Средний чек: **8 800 тг**
- Маржинальность (gross margin): **30%** → с учётом списаний реально **26–27%** (см. § 2а)
- Стоимость привлечения клиента (CAC): **2 500 тг**
- LTV (пожизненная ценность клиента): **28 000 тг**
- Retention rate (возврат клиентов): **35%** (к 6 месяцу)
- **Потери от порчи:** ~4–8% от CoGS на скоропортящихся товарах (~40–50% SKU-mix)

## 9. Выводы и рекомендации

**Положительные факторы:**
- Проект выходит на прибыль на 5–6 месяц после публичного запуска (Optimistic) / на 7–8 месяц (Realistic — см. [`MVP_PLAN.md`](./MVP_PLAN.md))
- Приемлемая маржинальность (30%)
- Низкий CAC благодаря партнёрству с АЗС и Telegram
- Хороший LTV/CAC (11.2x)

**Риски:**
- Ценовая чувствительность аудитории Костаная
- Высокая доля акций и скидок (20–25% выручки) снижает реальную маржу
- Возможное увеличение затрат на маркетинг при медленном росте

**Выводы и рекомендации:**
1. Начинать с минимального склада (250–350 м²).
2. Активно использовать Telegram + реферальную программу (самые дешёвые каналы).
3. Акцент на семейные наборы и свежие продукты — ключевое преимущество для Костаная.
4. Контролировать затраты на маркетинг (не более 12–15% от выручки).
5. Проводить ежемесячный анализ unit-экономики.
6. **Ежедневно списывать истёкшие/испорченные товары** через `InventoryAdjustments` (Reason=Spoilage) — это источник данных для контроля реальной маржи.
7. **Google Maps**: кэшировать результаты геокодинга для повторяющихся адресов; установить billing alert на $100/мес в Google Cloud.

## 10. Формула расчёта стоимости доставки

Поле `Orders.CalculatedDeliveryFee` вычисляет `DeliveryFeeCalculator` domain service:

```
CalculatedDeliveryFee =
  IF (TotalAmount >= 7 000 тг) → 0 тг (бесплатно)
  ELSE → BaseFee + Max(0, (DistanceKm - FreeDistanceKm) * PricePerExtraKm)
```

**Параметры (настраиваемые в appsettings):**

| Параметр | Значение по умолчанию |
|----------|-----------------------|
| `BaseFee` | 800 тг |
| `FreeDistanceKm` | 3 км |
| `PricePerExtraKm` | 200 тг/км |
| `FreeAboveOrderAmount` | 7 000 тг |

Расстояние получается из Google Maps Distance Matrix API (кэшировать по `(StoreLatLng, CustomerLatLng)` 30 мин в Redis).

`ActualDeliveryFee` может отличаться при применении промокода или специальной акции.
